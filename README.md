# 대기배출시설 및 방지시설 운영기록부 일일 작성 시스템

대기환경보전법 시행규칙 법정 서식 및 `대기배출 2026(0).xlsm` 양식을 기반으로 제작된 일일 운영기록부 작성 프로그램입니다.

---

## 주요 기능

1. **한 화면 듀얼 양식 편집 (앞면 / 뒷면)**
   - 좌측: 대기배출시설 운영기록부 (앞면 - 결재란, 날짜, 배출구 1~5 가동시간 및 비고, 방지시설 운전사항)
   - 우측: 방지시설 운영기록부 (뒷면 - 방지시설 보수사항, 자가측정사항, 연료/원료량, 기술인 의견 및 날인)
   - 원본 엑셀 셀 서식과 동일한 구조 및 클릭/입력 즉시 수정 가능

2. **김포시 월곶면 날씨 자동 연동**
   - 날짜를 변경하면 경기도 김포시 월곶면 기상 정보(날씨, 최저~최고온도, 습도, 기압, 풍향, 풍속)를 자동으로 조회하여 입력란에 세팅합니다.
   - 상단의 [⛅ 월곶면 날씨 연동] 버튼을 누르면 언제든 최신 날씨로 다시 불러올 수 있습니다.

3. **빠른 가동 프리셋 및 편리한 단축키**
   - [⚡ 전체 가동]: 배출구 1~4번을 `09:00 ~ 18:00` 및 `정상`으로 일괄 입력
   - [☕ 휴무/미가동]: 배출구 1~4번을 `-` 및 `미가동`으로 일괄 입력
   - 단축키: `Ctrl + S` 누르면 즉시 저장

4. **A4 용지 규격 2페이지 인쇄 및 PDF 저장**
   - 상단의 [🖨️ A4 인쇄 / PDF] 버튼을 누르면 브라우저 인쇄 창이 열리며, 정확히 앞면 1페이지, 뒷면 2페이지의 A4 규격으로 출력됩니다.

5. **데이터 영구 보관 및 엑셀 다운로드**
   - 작성된 기록은 `data/records.json`에 날짜별로 안전하게 저장됩니다.
   - [📊 엑셀 다운로드] 버튼으로 `.xlsx` 파일로 내보낼 수 있습니다.

---

## 실행 방법

1. `start.bat` 파일을 더블 클릭합니다.
2. 서버가 자동으로 실행되며 웹 브라우저(`http://localhost:3000`)가 열립니다.
3. 날짜를 선택하고 기록을 작성한 뒤 [💾 저장하기]를 누르면 완료됩니다.
